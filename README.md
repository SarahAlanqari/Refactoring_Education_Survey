# Refactoring Education Survey Artifacts

## Overview

This repository contains research artifacts associated with a questionnaire-based study examining how code quality, maintainability, and refactoring are addressed in undergraduate programming courses at King Khalid University (KKU), from both instructor and student perspectives.

The study investigates five dimensions:

1. Exposure to code quality concepts.
2. Code improvement practices.
3. Recognition of refactoring terminology.
4. Reinforcement through assessment and feedback.
5. Perceived challenges in teaching and learning code quality and refactoring.

The study provides descriptive evidence of reported teaching practices and student experiences. Its findings indicate partial alignment between instructors' and students' reported exposure, a gap between students' code-improvement practices and their recognition of refactoring terminology, and differences in reported assessment and feedback reinforcement. These findings are descriptive and should not be interpreted as evidence of statistically significant differences.

## Data Description

The study collected questionnaire responses from two groups:

- **Students:** Responses concerning exposure to code quality concepts, code improvement practices, recognition of refactoring terminology, assessment and feedback, and perceived challenges.
- **Faculty/instructors:** Responses concerning teaching practices, code quality instruction, refactoring, assessment and feedback, and perceived challenges.

The datasets are maintained separately to distinguish student and faculty/instructor perspectives.
